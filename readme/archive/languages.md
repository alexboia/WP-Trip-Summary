# Supported languages
<a name="wpts-langs"></a>  

The following languages are supported:

| Language | Code | Notes |
| --- | --- | --- |
| English | en_US | Also serves as default language |
| French | fr_FR | - |
| Romanian | ro_RO | - |
| German | de_DE | Partly contributed by [Nico](https://wordpress.org/support/users/nida78/), partly translated using Google Translate. |
